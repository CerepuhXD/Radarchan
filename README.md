# <p align="center">Radarchan(beta)</p>

Здравствуйте! Этот проект посвящён созданию свободного имиджбоарда, который позволит участникам общаться без цензуры с помощью mesh технологии передачи пакетов.

## Установка
Просто скачайте сборку и запустите главный файл (.exe) or (.py)

## Принцип работы
Он заключаеться в передаче пакетов с помощью mesh-сетей. Mesh сеть - это сеть в которой ноды(участники) общаються благодоря передаче пакетов(писем) друг другу.
Например:
*у нас есть письмо которое необходимо передать от участика А участнику И*
*всего в сети 5 участников: А, Б, В, Г, Д, Е, Ё, И*
возможная схема:

|     Д    
|А    Г    Б    В
|     Е    Ё    И

Всего существет только три оптимальных пути
*А -> Г -> Б -> В -> И*
*А -> Г -> Б -> Ё -> И*
*А -> Г -> Е -> Ё -> И*

Однако ваш компьютер не будет проверять весь маршрут целиком потому что если бы он это делал в огромной сети то просто захлебнулся от количества нод а лишь отправит их всем возможным соседям, в примере вы(А) сможете отправить пакет(письмо) только обьекту Г а тот её передаст и в Д и Б и Е, по сути механика схожа с работой квантовых алгоритмов которые чтобы пройти лабиринт проверяют все возможные точки. 

Цель этого алгоритма - создание одной огромной сети для создания имиджбоарда для общения например как 4chan.
